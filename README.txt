# MC Knifemaker — GitHub Pages

## How to publish
1. Open the repository `mcknifemaker.github.io` on GitHub.
2. Click **Add file → Upload files**.
3. Upload **everything inside this folder**: `index.html`, `style.css`, and the `assets` folder.
4. Commit the changes.
5. In **Settings → Pages**, make sure GitHub Pages is enabled from the `main` branch and `/ (root)`.
6. The site should publish at the repository's GitHub Pages address.

The images are already renamed to simple filenames so the links work on GitHub Pages.
